# LootLens — V75 Visual Roll bars

* Restores compact roll tracks with stat-colored progress, diamond markers,
fixed-roll dashes, and slim `ROLL` / `TIER` column labels.
* Shows tiers as plain `Tn` text without outlined boxes.
* Expands analyzer scaling from 80% through 180% and raises the fresh/default
scale to 140%.
* Adds an optional **Full stat colors** setting that applies each stat-family
color to modifier wording as well as accent lines and roll tracks.
